# 鑑定士 暗記トレーナー

不動産鑑定士試験（論文式・鑑定評価理論）向けに、**不動産鑑定評価基準**と**運用上の留意事項**を
重要度の高いものから順に、6か月で全範囲を暗記するための学習アプリ（PWA）です。
短答式の**行政法規**も今後追加できる構成にしています（現在は準備中）。

## 主な機能

- **全文収録**: 国土交通省公表のPDF（平成26年5月1日一部改正版）から本文を抽出し、見出し単位の暗記カード（約320枚・約8.4万字）に分割。数式・表は原文PDFから画像で切り出し。
- **重要度順の学習**: S（最重要）→A→B→C の順に新規カードを出題。重要度は一覧画面から自分用に変更可能。
- **6か月プラン**: 開始日・目標日（既定は6か月後）・総仕上げ期間（既定30日）から、1日の新規ノルマ（文字数）を自動計算。遅れたら翌日以降のノルマが自動で増える。
- **段階的に覚える暗記レベル**（間隔反復）
  - Lv0 通読 → Lv1 穴埋め30% → Lv2 穴埋め60% → Lv3 頭文字ヒント → Lv4 全文暗唱
  - 自己採点（もう一度／あやふや／できた／楽勝）で次回の復習日とレベルが決まる
  - Lv4 で2週間以上保持できたら「定着」
- **書いて答え合わせ**: Lv3以上で本文を入力すると、一致率と書けなかった箇所を表示（論文式対策）。
- **一覧・検索**: 章ごとの進み具合、キーワード検索、本文の通読。
- **オフライン対応・ホーム画面に追加可**（PWA）。学習記録は端末内に保存、JSONでバックアップ／復元。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト（6か月シミュレーションを含む）
npm run build    # 本番ビルド（dist/）
```

### 本文データの再生成

`data/raw/` の原文PDFから `src/data/kijun.json` と `public/figures/` を生成します（poppler-utils が必要）。

```bash
npm run content   # = python3 scripts/build_content.py --check
```

重要度の初期値は `scripts/build_content.py` の `IMPORTANCE_CHAPTER` / `IMPORTANCE_OVERRIDE` で調整できます。

### 公開（GitHub Pages）

`main` に push すると `.github/workflows/deploy.yml` でビルド・公開されます。
初回のみリポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください。

## 行政法規の追加（予定）

`src/subjects/types.ts` の `QuizQuestion` 形式で問題データを用意し、`src/subjects/index.ts` の
`gyosei` 科目に登録します。学習記録は科目ごとに分けて保存されるため、既存の記録には影響しません。

## 出典・注意

- 国土交通省「不動産鑑定評価基準」 https://www.mlit.go.jp/common/001043585.pdf
- 国土交通省「不動産鑑定評価基準運用上の留意事項」 https://www.mlit.go.jp/common/001083211.pdf

本文はPDFから自動抽出しているため、改行位置の復元や図表の切り出しに誤りが残っている可能性があります。
重要度（S/A/B/C）は出題傾向などからの目安です。
